## 0. 先看这几条（决定怎么落地）

### 0.1 尺寸换算

设计稿按 **390px** 宽（iPhone 13/14）。小程序 `750rpx` = 屏宽，所以：
$$1\text{px} = 750 \div 390 = 1.923\text{rpx}$$

### 0.2 渲染引擎必须用 WebView

**不要用 Skyline**。这套样式依赖三个 Skyline 不支持的能力：

| 能力 | 用在哪 | Skyline 支持情况 |
| :--- | :--- | :---: |
| 多层 `background-clip: padding-box, border-box` | 所有按钮的内嵌正面板 | ❌ 不支持 |
| `clamp()` 带百分比 | 所有积木的 `padding` | ❌ 不支持 |
| `-webkit-text-stroke` + `paint-order` | 所有贴纸字 | ❌ 不支持 |

> 在 `app.json` 或页面 `json` 里保持默认（`renderer: "webview"`）。

---

### 0.3 贴纸字描边有兼容风险

`-webkit-text-stroke` 在 iOS WKWebView 正常，部分安卓 webview 不支持 `paint-order: stroke fill`，结果是描边压在字上面、字变细。

#### 降级方案（写成全局 class，安卓走这套）：

```css
/* 安卓降级：8 方向 text-shadow 模拟描边 */
.sticker {
  color: #fff;
  text-shadow:
    -1.5px -1.5px 0 #6B2408,  1.5px -1.5px 0 #6B2408,
    -1.5px  1.5px 0 #6B2408,  1.5px  1.5px 0 #6B2408,
     0     -1.5px 0 #6B2408,  0      1.5px 0 #6B2408,
    -1.5px  0     0 #6B2408,  1.5px  0     0 #6B2408,
     1px    2px   0 rgba(110,24,10,.55);
}
```

**JS 判断**：`wx.getSystemInfoSync().platform === 'android'` 时给根节点加 `class="android"`。

## 1. 积木怎么画（核心原理，先懂这个再写组件）

### 1.1 三层结构

一块积木 = **斜面外壳** + **内嵌正面板** + **顶部凸点**

```text
┌──────────────────────────┐  ← ① 外壳：浅色渐变（--ft → --fb → --fb2）
│  ┌────────────────────┐  │     深色描边：box-shadow 0 0 0 3.5px --e
│  │                    │  │     底部厚度：box-shadow 0 5px 0 --sd
│  │   ② 正面板 --c     │  │
│  │   （饱和主色）     │  │
│  └────────────────────┘  │
└──────────────────────────┘
     ○    ○    ○            ← ③ 凸点：椭圆 + 中央深色凹孔
```

斜面带宽度 = 正面板 `inset`。上边最宽（约 13~15%），左右 5.5%，下边 5.5%，这样才有“从斜上方看积木”的透视感。

#### 凸点 CSS 实现

```css
.studs i {
  flex: 1 1 0; 
  min-width: 0; 
  position: relative;
  border-radius: 50% / 30%;          /* 椭圆，不是圆 */
  background-image: linear-gradient(180deg,
    var(--ft) 0%, var(--ft) 40%,    /* 顶盖亮 */
    var(--fb) 48%,                  /* 侧壁转折 */
    var(--fb2) 100%);               /* 底部暗 */
  box-shadow: 0 0 0 3px var(--e), 0 3px 5px rgba(60,25,8,.28);
}

/* 中央深色凹孔 —— 没有这个就不像乐高 */
.studs i::before {
  content: ""; 
  position: absolute;
  left: 21%; right: 21%; top: 8%; height: 24%;
  border-radius: 50%; 
  background: var(--e);
}
```

> 小号 `.studs.sm i::before` 覆盖为 `left/right 26%; top 10%; height 32%`（小尺寸要放大凹孔才看得见）。

### 1.6 摆放规则：故意不齐

| 规则 | 值 |
| :--- | :--- |
| **旋转范围** | `-2.5° ~ +2°`，同屏不重复角度 |
| **三连块（stk）** | `-2.4°` / `+1.6°` / `-1°`，配 `translateY(3px / -2px / 2px)` |
| **卡片错位** | 交替 `translateY(±3~4px)` + `margin-left: 7px` |
| **上限** | 旋转 $\le 3^\circ$，错位 $\le 8\text{px}$ |
| **关键** | **只转容器，不转字** —— 文字基线必须水平 |

#### 四张教材卡（bc）的既定角度

* **n1 红**：`rotate(-1.4deg)`
* **n2 蓝**：`rotate(1.2deg) translateY(4px)`
* **n3 紫**：`rotate(-.8deg)`
* **n4 绿**：`rotate(1.6deg) translateY(3px)`

### B 类：background-clip 三层（文字不会被遮，推荐给所有按钮）

```css
.opt, .speak, .ghost, .cta-sm, .search, .recent, .cheer, .chip, .chip.on {
  --bw: 5px;                           /* 斜面带宽 = border 宽度 */
  position: relative;
  border: var(--bw) solid transparent;
  border-radius: 15px/30%;
  background-color: var(--c);
  background-image:
    linear-gradient(180deg, rgba(255,255,255,.18), rgba(255,255,255,0) 42%, rgba(0,0,0,.05)), /* ① 光影 */
    linear-gradient(180deg, var(--c), var(--c)),                                                 /* ② 不透明正面板 */
    linear-gradient(180deg, var(--ft) 0 24%, var(--fb) 56%, var(--fb2) 100%);                    /* ③ 斜面 */
  background-clip:   padding-box, padding-box, border-box;
  background-origin: padding-box, padding-box, border-box;
  box-shadow:
    inset 0 0 0 1.5px rgba(70,35,10,.2),  /* 面板内描边 */
    0 0 0 3px var(--e),                   /* 外描边 */
    0 4px 0 var(--sd),                    /* 厚度 */
    0 5px 10px rgba(60,25,8,.28),
    0 13px 20px -10px rgba(60,25,8,.4);
}
```
> **原理**：② 层不透明且只画在 `padding-box`，正好遮住 ③ 层在内部的部分，于是 `border` 区露出 ③ 层的斜面 $\rightarrow$ 内嵌效果。`border-radius` 会自动给两层分别裁角。

## 4. 交互与动效

| 场景 | 效果 | 时长 |
| :--- | :--- | :--- |
| **主按钮按压** | `translateY(4px)` + 阴影从 5px 收到 2px（像压下去贴地） | 0.1s |
| **选项按钮按压** | `translateY(3px)` | 0.1s |
| **选中选项** | 白色 `outline 3px / offset -4px` 内框 | 即时 |
| **卡片入场** | 建议 `opacity 0 → 1` + `translateY(8px → 0)` + rotate 保持 | 220ms ease-out |
| **三连块入场** | 交错 60ms 延迟（左 → 右） | 220ms ease-out |
| **星星光圈** | scale $1 \leftrightarrow 1.06$ 呼吸 | 3s 无限 |
| **答对反馈** | 建议选项积木 scale $1 \rightarrow 1.06 \rightarrow 1$ + 星标弹入 | 260ms |

> ⚠️ **关键约束**：所有 transform 都要保留原有 rotate，不能只写 translateY，否则积木会“摆正”，破坏不齐感。

```css
/* 对的 */
.go:active  { transform: rotate(-1deg) translateY(4px); }

/* 错的，会瞬间摆正 */
.go:active  { transform: translateY(4px); }
```

> ⚠️ **踩坑注意**：`.studs` 必须是绝对定位 + flex。  
> 1. 父级若有 `.card > * { position: relative }` 之类的通用规则，会把凸点从 absolute 拉回文档流 $\rightarrow$ 凸点全部挤在左上角且宽度算成 0。  
> 2. 父级若有 `.card text { display: block }`，会打断 `.studs` 的 flex 布局 $\rightarrow$ 凸点宽度变 0，只剩 3px 描边阴影（看起来像一根细线）。  
> **解决办法**：给 `.studs` 写更高特异性的规则（如 `.plate > .studs { position: absolute; display: flex }`）。
